Marketer Companion — SEO & Marketing Toolkit

Your all-in-one browser companion for SEOs and digital marketers. Inspect URLs, audit pages, and pull performance data from Google Search Console, GA4, and CallRail — all in one focused, fast UI.

------

What's New in 0.8.2

Rebuilt interface and a stricter, more accurate blended report.

- One action bar on every panel — same button, same place, same name.
- Blended report is now the landing view, with a new segment selector in Settings: Organic search (default), Paid search, All paid, All organic, Social, Direct, Referral or All traffic.
- Sessions, key events and calls now always describe the same segment, so a percentage is never mislabelled.
- Organic now means Organic Search — organic social and video are no longer counted alongside your Search Console clicks.
- Organic calls count real search engines only. "Facebook Organic" is organic social, not organic search, and is excluded.
- Nothing fetches until you press Run, so no API quota is spent while you set a report up.
- Your property, GA4 property and CallRail account stay selected for the whole browser session.
- Rebuilt date picker: never clipped by the panel, with the selected range clearly highlighted.
- GA4 reporting expanded from 4 to 30 dimensions and 4 to 18 metrics, grouped and named the way GA4 names them.

------

WHAT IT DOES

- Blended report — Search Console, GA4 and CallRail side by side for one client, with period-over-period comparison, an interactive daily trend, and a segment you choose. Save a property, GA4 property and CallRail account together as a named client and switch between them in one click.
- GSC URL Inspection — Coverage status, canonicals, last crawl date, and robots status at a glance.
- GA4 Analytics — Users, sessions, views, events and key events, with 30 dimensions and 18 metrics, period-over-period comparison and CSV export.
- GSC Performance — Clicks, impressions, CTR and position across 7/28/90-day or custom date ranges, by query, page, country or device, with a whole-property or single-page toggle.
- CallRail Dashboard (API key required) — Account and company level call performance, call volume trends, sources, individual call records and transcripts, without leaving your browser.
- On-Page Audit (no API needed) — Reads the active tab's DOM to surface title, meta tags, robots/canonical, headings, and link and image counts.
- Structured Data (no API needed) — Finds JSON-LD, Microdata and RDFa on the active page and shows it as readable cards rather than raw JSON, with one-click links to Google's Rich Results Test and the Schema.org validator.
- Side panel — Run the same reports in Chrome's side panel so they stay open while you browse.

------

PRIVACY

- No developer server. Your data travels only between your browser and Google's and CallRail's own APIs.
- Google sign-in uses Chrome's identity service, or standard OAuth for a second account. Tokens are stored locally in your browser and never transmitted anywhere else.
- Your CallRail API key is kept only for the current browser session and is cleared when you close the browser.
- Cached report data is stored locally so reopening a report does not re-query the APIs.
- No analytics, advertising, error reporting or profiling of any kind. Nothing is sold or shared.
- Sign out anytime — one click clears stored accounts and cached data, and revokes the token with Google.
- Typography is loaded from Google Fonts, which means Google sees your IP address when the interface opens.

------

PERMISSIONS & WHY

- identity — Google OAuth sign-in to call Search Console and GA4 on your behalf.
- storage — Save your settings, selections and cached report data locally in your browser.
- activeTab — Read the active tab URL to scope audits and API requests.
- scripting — Inject a one-time content script for the On-Page Audit and Structured Data scan.
- sidePanel — Open the same interface in Chrome's side panel.

Host access is limited to the APIs the extension calls: Search Console, GA4, Google OAuth, and CallRail.

------

TIPS

- Use a GSC property that covers the URL you're inspecting — the extension tells you when it doesn't.
- GA4 auto-detects measurement IDs from the active tab and suggests the right property.
- Save a client once from the Blended report and switch between clients from the header.
- Set your default view in Settings if you report on paid or total traffic more often than organic.
- Nothing costs API quota until you press Run, so set up the report first.
